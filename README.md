# Heena Jindal — Portfolio

Live at: **[heena-portfolio-ten.vercel.app](https://heena-portfolio-ten.vercel.app/)**

A dark, animated, single-page portfolio built to showcase my AI/ML and full-stack projects — featuring a live neural-network canvas background, glassmorphism UI, scroll-driven project cards, and micro-interactions (tilt cards, magnetic buttons, animated stat counters).

## Built With
- **Frontend:** HTML5, CSS3 (custom, no framework), Vanilla JavaScript
- **Icons:** [Lucide](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## Features
- Custom neural-network canvas background with mouse interaction
- Glassmorphism cards with tilt-on-hover micro-interactions
- Scroll-driven "sticky stack" project showcase
- Animated count-up stats (CGPA, LeetCode progress)
- Fully responsive, with `prefers-reduced-motion` support

## Run Locally
This is a static site — no build step required.
```bash
git clone https://github.com/heena-jindal/heena-portfolio.git
cd heena-portfolio
# then just open index.html in a browser, or serve it:
npx serve .
```
