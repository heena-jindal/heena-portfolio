⭐ Featured AI Engineering Project

AI Study Companion

Problem: Traditional AI study assistants generate answers without verifying whether responses are grounded in study material, making them unreliable for learning and unable to adapt to a student's progress.

Solution: Built a production-oriented AI learning assistant combining Retrieval-Augmented Generation (RAG), Structured Outputs, LangGraph autonomous agents, persistent learning analytics, and LLM evaluation to generate reliable, personalized quizzes from uploaded study material.

  • 📄 Retrieval-Augmented Generation with ChromaDB for grounded responses.
  • 🤖 LangGraph ReAct Agent that autonomously selects tools based on user requests.
  • ✅ Structured quiz generation using Groq Structured Outputs and Pydantic validation.
  • 📊 SQLite-based learning history to identify weak topics and personalize quizzes.
  • 🔍 LLM-as-a-Judge evaluation pipeline to detect hallucinated responses.
  • 🚀 Modular backend architecture focused on reliability and maintainability.
